# react-native-native-diagnostics

Lightweight native diagnostics for React Native: battery, memory, CPU, thermal state, FPS and startup time via a typed TurboModule.

## Installation


```sh
npm install react-native-native-diagnostics
```


## Usage


```js
import { multiply } from 'react-native-native-diagnostics';

// ...

const result = multiply(3, 7);
```
